# 学習ログ

HTML/CSS/JavaScriptとlocalStorageだけで動く、日々の学習を記録する小さなアプリです。

日付ごとに「今日の調子」と「今日の学習メモ」を保存できます。数学の問題、英単語の復習、読書メモなどを短く記録し、あとから学習の積み重ねを見返せます。記録はブラウザのlocalStorageに保存されます。

このリポジトリは、学習ログアプリに育てるための土台として使います。

## デモの動かし方

`index.html` をブラウザで開くだけで使えます。ビルドやサーバー起動は不要です。

```text
my-study-log/
├── index.html
├── styles.css
├── app.js
├── README.md
└── LICENSE
```

## 機能

- 今日の日付を自動セット
- 今日の調子を5段階から選択
- 学習メモを保存
- 日付ごとに1件の記録として保存
- 同じ日付で保存すると上書き
- 学習記録の一覧表示、編集、削除
- 学習メモの検索
- 今日の調子による絞り込み
- 最近7件の学習コンディションの推移表示

## 使用技術

- HTML
- CSS
- JavaScript
- localStorage

外部ライブラリは使っていません。

## localStorage

保存キーは `tiny-diary.entries.v1` です。

データは次のような配列で保存されます。

```json
[
  {
    "id": "example-id",
    "date": "2026-04-29",
    "mood": "happy",
    "note": "今日は少しうまくいった",
    "createdAt": "2026-04-29T10:00:00.000Z",
    "updatedAt": "2026-04-29T10:00:00.000Z"
  }
]
```

## 今日の調子

調子は次の5種類です。

| 値 | 表示 | スコア |
| --- | --- | --- |
| `happy` | よく集中 | 5 |
| `calm` | まあまあ | 4 |
| `normal` | ふつう | 3 |
| `tired` | 少し疲れた | 2 |
| `sad` | 休憩したい | 1 |

最近7件の記録をこのスコアに変換し、学習コンディションの推移として表示します。

## 教材で説明しやすい流れ

1. フォームから日付、調子、学習メモを受け取る
2. JavaScriptの配列に学習記録を追加する
3. `JSON.stringify` でlocalStorageへ保存する
4. `JSON.parse` でlocalStorageから読み込む
5. 配列をもとに記録一覧とコンディションの推移を再描画する

記録の例: 「数学の問題を5問解いた」「英単語を10語復習した」「読書メモをまとめた」。
